# power-supply-7805
## Особенности реализации (Топология платы)
* Среда проектирования: **Altium Designer**
* Количество слоев: **1 слой (Односторонняя печатная плата)**. Проект разработан с учетом минимизации стоимости серийного производства.
* **Тепловой менеджмент (Thermal Design):** Отвод тепла от микросхемы LM7805 реализован за счет создания максимально возможной площади медного полигона непосредственно на сигнальном слое вокруг вкладки (Tab) регулятора.
* **Трассировка:** Компоновка элементов выполнена оптимальным образом, что позволило полностью избежать пересечения проводников на одном слое и отказаться от использования проволочных перемычек (Jumpers).
* Фильтрующие керамические конденсаторы С1 и С3 (0.1 мкФ) размещены в максимальной физической близости к выводам питания микросхемы.
